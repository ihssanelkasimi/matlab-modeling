# Commande vectorielle d'un PMSM avec onduleur bidirectionnel à deux niveaux (Simscape)

Simulation sous MATLAB/Simulink (Simscape) de la commande vectorielle d'un moteur synchrone à aimants permanents (PMSM) alimenté par un onduleur bidirectionnel à deux niveaux.

Contenu :

- Modèle Simscape du PMSM et de l'onduleur à deux niveaux
- Commande vectorielle (régulation de vitesse et des courants id/iq)
- Résultats de simulation (vitesse, couple, courants)

Technologies : MATLAB, Simulink, Simscape.
